# Section Tally Conversational AI – Reproducibility Artifacts

This repository contains reproducibility artifacts associated with the IEEE EDUCON 2026 paper:

**“Governed Conversational Analytics for Course Discovery Using ThoughtSpot, LLM-SQL, and RAG Pipelines.”**

The repository offers examples of prompt templates, few-shot mappings, SQL translations, and architectural figures used in the study. All artifacts are simplified to keep institutional confidentiality while keeping logical and methodological accuracy.

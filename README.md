# Section Tally Conversational AI – Reproducibility Artifacts

This repository contains reproducibility artifacts associated with the IEEE EDUCON 2026 paper:

**“AI-Powered Course Discovery: Leveraging Prompt Engineering, Feedback Loops, and Guardrails for Institutional Context”**

The repository offers examples of prompt templates, few-shot mappings and SQL translations used in the study. All artifacts are simplified to keep institutional confidentiality while keeping logical and methodological accuracy.
